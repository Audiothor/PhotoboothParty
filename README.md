## Version Française

**PhotoboothParty** est une application moderne et interactive de cabine photographique (Photobooth) conçue pour animer vos événements (mariages, anniversaires, soirées). Elle transforme n'importe quelle tablette ou téléphone Android, PC Windows ou Mac en une cabine photo autonome et personnalisable.

### 🌟 Caractéristiques principales
- **Déclenchement par télécommande Bluetooth** : Prenez des photos à distance à l'aide d'un simple bouton de télécommande de présentation ou d'obturateur de selfie Bluetooth (clé "Volume Haut" ou "Entrée").
- **Personnalisation complète de l'écran d'accueil** : Personnalisez jusqu'à 3 lignes de texte en choisissant précisément le texte, la taille (via un curseur fluide) et la couleur (via une palette visuelle moderne de pastilles).
- **Gestion des flashs** : Profitez à la fois d'un flash matériel de caméra (Auto, Forcé, Désactivé) et d'un flash virtuel plein écran blanc pour illuminer le visage des sujets lors des selfies.
- **Minuteurs ajustables** : Définissez le compte à rebours avant la prise de photo, la durée d'affichage de l'aperçu et le délai d'inactivité avant le retour automatique à l'accueil.
- **Stockage personnalisé** : Choisissez d'enregistrer les photos directement dans la galerie par défaut ou dans le dossier spécifique de votre choix (clé USB, dossier partagé).
- **Anti-veille automatique** : Maintient l'écran allumé pendant toute la durée de l'événement.

### 📦 Guide d'installation (Facile pour les non-techniques)

L'application est conçue pour être installée très facilement sur vos appareils de fête, en particulier sur **tablette Android** (le support idéal).

#### 📱 Sur Android (Tablette / Téléphone) - *Recommandé*
1. **Télécharger l'application** : Sur votre appareil Android, ouvrez votre navigateur web et rendez-vous sur la page des [Releases (Versions) du projet sur GitHub](https://github.com/Audiothor/PhotoboothParty/releases). Téléchargez le fichier se terminant par `.apk` (généralement `com.companyname.PhotoboothParty-Signed.apk`).
2. **Autoriser l'installation** : 
   - Lors de l'ouverture du fichier `.apk` téléchargé, Android peut vous indiquer que l'installation d'applications issues de sources inconnues est bloquée par sécurité.
   - Cliquez sur **Paramètres** dans la boîte de dialogue qui s'affiche, puis cochez l'autorisation pour votre navigateur (Chrome) ou gestionnaire de fichiers afin de lui permettre d'**Installer des applications inconnues** (ou "sources inconnues").
3. **Installer** : Retournez sur le fichier `.apk` téléchargé et cliquez sur **Installer**. Une fois l'opération terminée, l'icône **PhotoboothParty** apparaîtra sur votre écran d'accueil.

#### 💻 Sur Windows (PC / Tablette Windows)
1. Téléchargez le fichier d'installation Windows se terminant par `.msix` depuis la page des [Releases du projet sur GitHub](https://github.com/Audiothor/PhotoboothParty/releases).
2. Double-cliquez sur le fichier `.msix` et cliquez sur le bouton **Installer** dans la boîte de dialogue qui apparaît.

## English Version

**PhotoboothParty** is a modern and interactive photo booth application designed to light up your events (weddings, birthdays, parties). It transforms any Android tablet, phone, Windows PC, or Mac into a fully customizable, standalone photo booth.

### 🌟 Key Features
- **Bluetooth Remote Trigger**: Snaps photos from a distance using any standard Bluetooth selfie clicker, presenter, or button (triggering "Volume Up" or "Enter" keys).
- **Fully Customizable Home Screen**: Customize up to 3 text overlay lines with real-time size adjustments (using visual sliders) and premium colors (using a curated modern color palette).
- **Advanced Flash Controls**: Combine physical hardware camera flash (Auto, Forced, Disabled) with a simulated full-screen white flash effect for beautiful selfie illumination.
- **Configurable Timers**: Set custom countdown times, preview display durations, and inactivity timeouts before returning to the main screen.
- **Custom Gallery Folder**: Save pictures directly to the default device gallery or choose a custom target directory (external USB drive, shared folder).
- **Keep Screen On**: Prevents the screen from dimming or locking during your party.

### 📦 Installation Guide (Simple & Non-Technical)

The application is highly optimized for **Android tablets** (the ideal physical setup for a photo booth).

#### 📱 On Android (Tablets / Phones) - *Recommended*
1. **Download the App**: On your Android device, open the browser and navigate to the [GitHub Releases page](https://github.com/Audiothor/PhotoboothParty/releases). Download the file ending with `.apk` (typically `com.companyname.PhotoboothParty-Signed.apk`).
2. **Enable Installation from Unknown Sources**:
   - Open the downloaded `.apk` file. A security prompt might appear, warning you that installing unknown apps is blocked.
   - Click **Settings** in that prompt, and enable **Allow from this source** (or "Install unknown apps") for your file manager or browser.
3. **Install**: Return to the downloaded `.apk` file, click **Install**, and once completed, tap the **PhotoboothParty** icon on your home screen to launch.

#### 💻 On Windows (PC / Windows Tablet)
1. Download the Windows installation file ending with `.msix` from the [GitHub Releases page](https://github.com/Audiothor/PhotoboothParty/releases).
2. Double-click the `.msix` installer and select the **Install** button.
